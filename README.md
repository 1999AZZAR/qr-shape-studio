# QR Shape Studio

A local web application for generating customizable QR codes. Built with React, TypeScript, and Vite.

## Features

- Custom dot shapes: Square, rounded, circle, diamond, and custom SVG paths.
- Custom colors for foreground and background, including transparent backgrounds.
- Logo insertion with configurable sizing and clear space.
- Export to SVG and PNG formats.
- Adjustable error correction levels (L, M, Q, H).

## Prerequisites

- Node.js 18 or later

## Setup

1. Install dependencies:
   ```sh
   npm install
   ```

2. Start the development server:
   ```sh
   npm run dev
   ```
   The application will be available at `http://127.0.0.1:5173/`.

## Build and testing

To build the application for production:
```sh
npm run build
```

To run the test suite:
```sh
npm run test
```
